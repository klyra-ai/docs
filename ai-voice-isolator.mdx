[AI Voice Isolator](https://klyra.ai/apps/ai-voice-isolator) helps you clean spoken audio by removing unwanted background noise such as street noise and microphone feedback. Upload an audio file, isolate the voice, and review the processed result.

<Note>
  AI Voice Isolator is designed for voice-focused audio cleanup. The goal is to make the speaker's voice clearer by reducing unwanted background noise.
</Note>

## How AI Voice Isolator works

<Steps>
  <Step title="Upload your audio">
    Choose an audio file by dragging and dropping it into the upload area or selecting **Browse**.
  </Step>
  <Step title="Isolate the voice">
    Once the file is uploaded, select **Isolate Voice** to start processing.
  </Step>
  <Step title="Review the result">
    The processed audio appears in the workspace so you can play and review it.
  </Step>
  <Step title="Use the processed audio">
    Once the result meets your needs, use the processed audio in your workflow.
  </Step>
</Steps>

## What AI Voice Isolator does

AI Voice Isolator is engineered to remove unwanted background noise and improve voice clarity.

It can help reduce sounds such as:

- Street noise
- Microphone feedback
- Other unwanted background noise

The result is intended to present the speaker's voice with greater clarity.

## Step 1: Upload your audio

The upload panel provides two ways to add audio:

- **Drag and drop** the file into the upload area.
- Click **Browse** and select the file from your device.

The interface shown supports:

- MP3
- MP4
- OGG
- MPEG
- MPGA
- M4A
- WAV
- WEBM

The interface specifies a **maximum audio file size of 500MB**.

<Note>
  Use a supported format and keep the file within the displayed size limit.
</Note>

### Confirm the uploaded file

After the file is accepted, Klyra displays the uploaded filename in the upload area with a confirmation indicator.

In the example shown, the uploaded file is `do-you-wanna-coffee.mp4`. The file also appears in the audio item card on the right.

## Step 2: Isolate the voice

After the audio has been uploaded, click **Isolate Voice**.

</Frame>

Klyra then processes the recording to reduce unwanted background noise and isolate the speaker's voice.

## Best practices

### Start with a usable recording

Voice isolation can improve a recording, but source quality still matters. Whenever possible, start with an understandable recording where the speaker's voice is reasonably audible.

### Use supported formats

The interface supports MP3, MP4, OGG, MPEG, MPGA, M4A, WAV, and WEBM.

### Check the file size

The displayed maximum audio file size is **500MB**.

### Review before using the final audio

Listen to the processed recording before using it in a video, presentation, podcast, social post, or other production workflow.

### Keep the original file

Keep your original recording available so you can compare the processed result or run another version through your workflow.

## Troubleshooting

### My file is not uploading

Check that:

1. The file uses one of the supported formats.
2. The file is within the displayed 500MB maximum.
3. Your browser connection is stable.
4. You can try **Browse** if drag and drop does not work.

### I cannot start voice isolation

Make sure an audio file has been successfully uploaded and is displayed in the upload area. The **Isolate Voice** action is intended to be used after a file has been selected.

### The result still contains some background noise

Voice isolation is designed to reduce unwanted background noise and improve voice clarity. Results can vary depending on the source recording and the type of background noise. Review the processed audio before using it as a final production asset.

### I want to process another recording

Upload another supported audio file and repeat:

**Upload → Isolate Voice → Review**
