[AI Image Studio](https://klyra.ai/apps/ai-music-generator) is Klyra AI's image workspace for creating new images and transforming existing ones. You can describe an image, choose an AI provider, generate a result, and continue working from the same workspace.

This tutorial covers the complete AI Image Studio editing toolkit, including 12 image-editing workflows, along with image generation and Gallery.

<Note>
  The screenshots in this guide reflect the current AI Image Studio interface and the workflows tested during product verification. Provider availability and output behavior may change as Klyra AI updates its integrations.
</Note>

## 1. Start with AI Image Studio

Open **AI Image Studio** from Klyra AI. The main workspace combines image creation, editing shortcuts, and your recent Gallery in one place.

<Frame>
  ![AI Image Studio image generation composer](/images/ai-image-studio/01-ai-image-studio-interface.webp)
</Frame>

### What you can do from the workspace

The workspace gives you access to:

- A prompt composer for describing the image you want to create.
- Image generation controls such as the generation mode, model, aspect ratio, and additional options.
- A set of image editing workflows.
- A Gallery area for recently generated images.
- A dedicated Gallery view for browsing and managing generated images.

The editing area currently includes workflows such as Merge Face, Generative Fill, Reimagine, Remove Background, Cleanup, Upscaler, Replace Background, Sketch to Image, Remove Text, Inpainting, Style Transfer, and Image Relight.

## 2. Generate an image

Image generation is the starting point when you want to create a new visual from a description.

<Frame>
  ![AI Image Studio workspace](/images/ai-image-studio/02-ai-image-studio-prompt.webp)
</Frame>

### Step 1: Describe what you want

Enter a clear description in the prompt field.

A useful prompt normally describes:

- The subject
- The environment
- The visual style
- Lighting
- Composition
- Important details that should remain visible

For example:

> A premium modern workspace at sunrise, large windows overlooking a city skyline, elegant wooden desk, laptop, indoor plants, warm natural light, photorealistic commercial photography, sophisticated and minimal, high detail.

### Step 2: Choose the image mode

The composer includes an **Image** mode for image generation.

### Step 3: Choose a model

Select the model you want to use from the model selector. The workspace includes models from providers such as Google and OpenAI.

<Note>
  Model availability and the exact model list can change as Klyra AI adds or updates provider integrations.
</Note>

### Step 4: Choose the aspect ratio

The composer provides an aspect-ratio control. **Auto** can be used when you want the system to determine an appropriate output format.

### Step 5: Use additional controls when needed

Use **More** when you need additional generation controls. Keep the prompt focused first, then add extra controls when they provide a clear benefit.

### Step 6: Generate

Click **Generate** to create the image.

<Note>
  The amount displayed by the interface is the media capacity cost for that generation. Actual cost can depend on the selected model and configuration.
</Note>

## 6. Merge Face

Merge Face lets you swap or blend a face between two images.

<Frame>
  ![Merge Face interface](/images/ai-image-studio/01-merge-face-interface.webp)
</Frame>

### Step 1: Upload the main image

Use the main upload area to add the image you want to edit. You can drag and drop an image or select **Browse Files**.

The upload interface accepts:

- PNG
- JPG
- WebP
- Maximum file size: **20 MB**

<Frame>
  ![Merge Face interface input](/images/ai-image-studio/02-merge-face-input-main.webp)
</Frame>

### Step 2: Add the face reference

In **Face Reference**, select **Choose file** and upload the face you want to merge. A clear, front-facing reference works best.

<Frame>

The interface provides:

- OpenAI (GPT Image)
- Stability AI
- Google Gemini

## 18. Common workflow

Most AI Image Studio editing tasks follow the same pattern:

1. Open the required editing workflow.
2. Upload the source image.
3. Select an AI provider.
4. Add instructions when the workflow provides them.
5. Select **Generate**.
6. Review the result.
7. Use **Change** when you want another variation.
8. Use **Download** when the result is ready.

## 19. Prompting best practices

### Describe the outcome

Start with what you want the final image to look like.

### Tell the model what to preserve

For transformations, explicitly identify important elements that must remain unchanged.

### Be specific about placement

For edits that add or remove objects, describe the exact location and relationship to nearby elements.

### Match the existing scene

Mention perspective, lighting, materials, shadows, scale, and depth when the edit needs to look naturally integrated.

### Iterate when necessary

Use **Change** when you want another result rather than rebuilding the workflow from the beginning.

## Troubleshooting

### The result does not match the prompt

Make the instruction more specific. Identify the subject, desired change, elements to preserve, placement, lighting, and style.

### The edited image changes too much

Explicitly tell the model what must remain unchanged.

### Added content does not blend naturally

Describe perspective, scale, materials, light direction, shadows, and depth of field.

### The background replacement changes the subject

State that the subject must remain unchanged, including facial features, clothing, pose, proportions, and important details.

### The upscaled result is much larger than expected

Check the output dimensions and file size before downloading or using the image in another workflow.

### Remove Background does not produce the transparency I need

Try **Stability AI**, which is the recommended provider in the current workflow for transparent-background output.

### One provider gives a weaker result

Try another available provider and compare the outputs.
