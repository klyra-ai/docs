[AI Blogger](https://klyra.ai/apps/ai-blogger) helps you build a repeatable blogging workflow inside Klyra. Create an AI Blogger Agent with your topics, writing style, SEO preferences, WordPress connection, and publishing cadence. Then use the agent to generate posts as drafts, review them, and publish or schedule them.

<Note>
  AI Blogger is designed around a review-first workflow. Generating posts creates drafts for you to review before publishing.
</Note>

## How AI Blogger works

<Steps>
  <Step title="Create an AI Blogger Agent">
    Define what the agent should write about, how it should sound, how its content should be structured for SEO, where it should publish, and how often it should publish.
  </Step>
  <Step title="Generate posts">
    Use the agent to generate one or more new blog posts. Generated posts are added as drafts.
  </Step>
  <Step title="Review and edit">
    Open a draft, review the title and article, update the content if needed, and review categories, tags, and SEO metadata.
  </Step>
  <Step title="Publish or schedule">
    Publish the post immediately or schedule it for a future date and time.
  </Step>
</Steps>

## Before you start

You will need:

- Access to Klyra AI.
- A WordPress website if you want the agent to publish automatically to WordPress.
- A WordPress username with the required permissions.
- A WordPress Application Password for the connection.

<Warning>
  Do not use your normal WordPress account password in the WordPress connection. AI Blogger uses a WordPress Application Password.
</Warning>

## Create your first AI Blogger Agent

Open **AI Blogger** from the Klyra sidebar, then choose **Create AI Blogger**.

The agent setup contains five steps:

1. Topics
2. Voice & Tone
3. SEO
4. WordPress
5. Schedule

<Frame>
  ![AI Blogger dashboard showing the Create AI Blogger button and agent overview](/images/ai-blogger/01-ai-blogger-dashboard.webp)
</Frame>

### Step 1: Define your topics

The **Topics** step tells your agent what it should write about.

Enter:

- **Agent Name**: The name you will use to identify the agent in Klyra.
- **Topics**: The subjects the agent should cover.
- **Target Keywords**: Keywords the agent should naturally use in its posts.

Example:

| Field | Example |
| --- | --- |
| Agent Name | AI Business Blog |
| Topics | Artificial Intelligence, AI for Business, AI Productivity, Business Automation |
| Target Keywords | AI for business, AI productivity, AI automation, business AI tools |

<Frame>
  ![AI Blogger Create Agent Topics step showing agent name, topics, and target keywords](/images/ai-blogger/02-create-agent-topics.webp)
</Frame>

<Note>
  Keep your topics focused. An agent with a clear subject area is easier to keep consistent than an agent that covers unrelated subjects.
</Note>

Click **Continue**.

### Step 2: Set the voice and tone

The **Voice & Tone** step controls how your agent should sound.

The writing tone options shown in the interface include:

- Professional
- Friendly
- Direct
- Technical
- Casual
- Authoritative

You can also add **Custom Style Rules** for repeatable writing guidance.

Example:

> Use clear, practical language. Focus on business outcomes and real-world examples. Avoid unnecessary jargon, hype, and exaggerated claims. Use concise paragraphs and active voice.

<Frame>
  ![AI Blogger Create Agent Voice and Tone step showing writing tone options and custom style rules](/images/ai-blogger/03-create-agent-voice-tone.webp)
</Frame>

Click **Continue**.

### Step 3: Configure SEO preferences

The **SEO** step controls the default search-focused structure of generated content.

#### Keyword density

The screenshot shows:

**Medium (2-3%) - Balanced**

The interface recommends Medium for most content.

#### Metadata limits

Set:

- **Meta Title Max**
- **Meta Desc. Max**

The example configuration uses:

- Meta Title Max: **60**
- Meta Desc. Max: **160**

#### Content structure

You can enable:

- **H2 headings**
- **H3 sub-headings**
- **FAQ section**
- **Bullet lists**

<Frame>
  ![AI Blogger SEO Preferences step showing keyword density, metadata limits, and content structure options](/images/ai-blogger/04-create-agent-seo.webp)
</Frame>

Click **Continue**.

### Step 4: Connect WordPress

The **WordPress Connection** step connects your website so the agent can publish automatically.

Enter:

- **WordPress Site URL**
- **WordPress Username**
- **Application Password**

The Site URL should include `https://`. The interface indicates that no trailing slash is needed.

<Frame>
  ![AI Blogger WordPress Connection step showing site URL, username, application password, and Test Connection](/images/ai-blogger/05-create-agent-wordpress.webp)
</Frame>

#### Create a WordPress Application Password

If you do not already have one:

1. Sign in to your WordPress administrator dashboard.
2. Open your user profile.
3. Find **Application Passwords**.
4. Enter a name, such as `Blogger Agent`.
5. Create the application password.
6. Copy the generated password and enter it into Klyra.

<Frame>
  ![WordPress Application Passwords screen showing an existing Blogger Agent application password](/images/ai-blogger/07-wordpress-application-passwords.webp)
</Frame>

<Warning>
  Treat the Application Password like a credential. Do not publish it in documentation, screenshots, messages, or source code. Revoke it from WordPress when it is no longer needed.
</Warning>

#### Test the connection

Click **Test Connection**.

A successful connection is confirmed by the success message shown in Klyra.

<Frame>
  ![AI Blogger WordPress connection screen showing a successful connection](/images/ai-blogger/05-create-agent-wordpress-success.webp)
</Frame>

Click **Continue**.

### Step 5: Choose the publishing cadence

The **Schedule** step defines the agent's default publishing cadence.

| Option | What it means |
| --- | --- |
| **Manual** | You decide when to publish each post. |
| **Daily** | One post per day from drafts. |
| **Weekly** | One post per week from drafts. |
| **Custom** | Choose your own interval in hours. |

The interface notes that the publishing cadence can be overridden per post.

<Frame>
  ![AI Blogger Publishing Cadence step showing Manual, Daily, Weekly, and Custom options](/images/ai-blogger/06-create-agent-schedule.webp)
</Frame>

<Note>
  Agent-level Publishing Cadence is different from scheduling one specific post from the Edit Post screen.
</Note>

### Create the agent

After completing all five steps, click **Create Agent**.

Your new agent appears under **My Agents**.

<Frame>
  ![AI Blogger workspace showing an AI Business Blog agent](/images/ai-blogger/01-ai-blogger-dashboard.webp)
</Frame>

An agent card can include:

- Agent name
- Active or inactive status
- Connected WordPress site
- **Generate**
- **Edit**
- **Delete**

## Generate blog posts

From **My Agents**, click **Generate** on the agent you want to use.

The **Generate Posts** dialog opens.

Enter the number of posts you want to create. The interface allows up to **100 posts at a time**.

For your first run, start with a small batch so you can review the output and refine the agent if needed.

<Frame>
  ![Generate Posts dialog showing the number of posts field and Start generation button](/images/ai-blogger/08-generate-posts.webp)
</Frame>

Click **Start generation**.

<Note>
  Generated posts are added as drafts. Generation does not mean that posts are immediately published.
</Note>

## Review your generated posts

Open **Posts** from the AI Blogger workspace.

The Posts page provides status filters for:

- **All**
- **Drafts**
- **Scheduled**
- **Published**
- **Failed**

<Frame>
  ![AI Blogger Posts page showing generated draft posts and post actions](/images/ai-blogger/09-posts-drafts.webp)
</Frame>

Post rows can show the:

- Title
- AI model
- Topic or tag information
- Status
- Date
- Available actions

Available actions shown include:

- **Publish**
- **Schedule**
- **Edit**
- **Delete**

### Understand the post lifecycle

```text
Generated
   ↓
Draft
   ↓
Review and edit
   ↓
Publish now OR schedule
   ↓
Published
```

A post that does not publish successfully can appear under **Failed**.

## Edit and review a post

Open a draft using **Edit**.

The **Edit Post** screen provides the content editor and publishing controls.

<Frame>
  ![AI Blogger Edit Post screen showing the article editor, publishing controls, taxonomy, SEO metadata, and post details](/images/ai-blogger/10-edit-post.webp)
</Frame>

### Edit the title

The generated title appears at the top of the editor and can be changed before publishing.

### Edit the article

The article is displayed in a rich text editor. Review and modify the generated content, including headings, formatting, lists, links, and other supported editor elements.

<Note>
  Review AI-generated content before publishing. Check factual claims, examples, names, statistics, links, formatting, and whether the article meets your intended search intent.
</Note>

### Review categories and tags

The **Taxonomy** section contains:

- **Categories**
- **Tags**

Both fields use comma-separated values.

Example:

**Categories**

> Technology, Marketing

**Tags**

> ai, blogging

### Review SEO metadata

The **SEO Metadata** section includes:

- **Meta Title**
- **Meta Description**
- **Featured Image URL**

The interface displays character counters for the meta title and description.

### Review post details

The **Details** panel shows information such as the AI model used and when the post was created.

## Save, publish, or schedule

### Save Changes

Use **Save Changes** to keep your edits without publishing the article.

### Publish Now

Use **Publish Now** when the article is ready to be published immediately.

Before publishing, confirm the title, content, taxonomy, SEO metadata, and WordPress connection.

### Schedule Publish

Use **Schedule Publish** when you want the article to go live at a future date and time.

Remember:

- **Publishing Cadence** = the agent's default publishing rhythm.
- **Schedule Publish** = the publication schedule for an individual post.

## Manage your AI Blogger Agents

Return to **My Agents** to manage configured agents.

### Enable or disable an agent

Use the toggle on the agent card to control whether the agent is active.

### Edit an agent

Use **Edit** when you want to change topics, keywords, voice, SEO preferences, WordPress settings, or publishing cadence.

### Generate more posts

Use **Generate** to create another batch of draft posts.

### Delete an agent

Use **Delete** when the agent is no longer needed.

<Warning>
  Deleting an agent is different from deleting an individual post. Review what you are removing before confirming the action.
</Warning>

## Best practices

### Keep each agent focused

Use separate agents for substantially different content strategies.

### Use relevant target keywords

Add keywords that genuinely match the topics you want the agent to cover.

### Make Custom Style Rules specific

Good rules describe observable writing behavior, such as using active voice, concise paragraphs, practical examples, and plain language.

### Review before publishing

Check factual accuracy, statistics, links, claims, structure, and SEO metadata before publishing.

### Start with drafts

For a new agent, generate a small batch first. Refine the configuration before scaling up.

## Troubleshooting

### The WordPress connection fails

Check:

1. The WordPress URL includes `https://`.
2. There is no unnecessary trailing slash.
3. The username is correct.
4. You used a WordPress Application Password.
5. The Application Password has not been revoked.
6. You can run **Test Connection** again.

### The generated posts do not match my preferred style

Review **Voice & Tone**, including the selected tone and Custom Style Rules. Also review your Topics and Target Keywords.

### I generated posts but they are not published

Generated posts are added as **drafts**. Open **Posts → Drafts**, review the content, then use **Publish Now** or **Schedule Publish**.

### I want to change when a specific post goes live

Open the post and use **Schedule Publish**. This is separate from the agent-level **Publishing Cadence**.
